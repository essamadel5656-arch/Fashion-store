# 🛍️ Fashion Store (Under Development)

## 🚀 التقنيات المستخدمة (Tech Stack)
* **Framework:** Laravel 12 (Latest Version)
* **Database:** MySQL
* **Frontend:** Bootstrap 5
* **Architecture:** MVC
